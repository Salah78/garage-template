# Exigence Auto — Template Vitrine Automobile Premium

**Exigence Auto** est une expérience digitale haut de gamme conçue pour un garage de réparation et d'entretien automobile. Ce projet s'éloigne des standards classiques pour proposer une interface moderne, rassurante et axée sur la précision technique.

## 🏁 Concept Créatif

L'identité visuelle repose sur le concept de **"Précision Mécanique"**. L'objectif est de transformer l'image du garage traditionnel en un lieu d'excellence technique, propre et structuré, inspiré des paddocks de course et de l'ingénierie de pointe.

- **Palette de Couleurs** : Fond Noir Profond & Gris Graphite, contrasté par un Orange Brûlé (Cuivre) pour souligner la maîtrise et la technicité.
- **Typographie** : Duo percutant de `Outfit` (Headings) et `Inter` (Body) pour un aspect à la fois imposant et clinique.
- **Expérience** : Animations fluides avec Framer Motion pour rythmer la lecture et renforcer l'aspect "qualité de service".

## 🛠 Stack Technique

- **Framework** : [Next.js 16 (App Router)](https://nextjs.org/)
- **Langage** : TypeScript
- **Styling** : [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations** : [Framer Motion](https://www.framer.com/motion/)
- **Icônes** : Lucide React

## 📂 Architecture du Projet

- `src/sections/` : Composants de page complets (Hero, Services, Atelier, Process, etc.).
- `src/components/` : Composants UI réutilisables (Boutons, Navbar, Footer).
- `src/app/` : Configuration globale, layout et routage.
- `src/lib/` : Utilitaires et fonctions partagées.

## 🚀 Installation

1. Cloner le projet :
   ```bash
   git clone https://github.com/Salah78/garage-template.git
   ```

2. Installer les dépendances :
   ```bash
   npm install
   ```

3. Lancer le serveur de développement :
   ```bash
   npm run dev
   ```

4. Builder pour la production :
   ```bash
   npm run build
   ```
